# v1.0.1

公開日: 2026-08-30

v1.0.1はCLIの不具合修正と、実際に動かせるPost Exampleを中心としたパッチリリースです。既存APIを削除する変更はありません。

## CLIの修正

`routes`と`openapi`で、先頭の`--module`オプションが内部のサブコマンドとして誤って消費される問題を修正しました。

修正前は次のコマンドが`Missing --module`で失敗していました。

```bash
npx honolus openapi \
  --module ./dist/app.js \
  --output openapi.json
```

v1.0.1では同じコマンドでOpenAPI 3.0.3文書を生成できます。

また、`routes`が大きなJSONを標準出力へ書き出す際、flush完了前にprocessが終了する可能性があったため、書き込み完了を待つように変更しました。

## CLIの回帰テスト

次の呼び出しを自動テストへ追加しました。

- `honolus routes --module <file>`
- `honolus openapi --module <file> --output <file>`

CLI処理は`runCli()`として分離され、subprocessに依存せず引数と出力をテストできます。

## Post Example

[`example/`](https://github.com/Untitled-Sekai/Honolus/tree/main/example)を責務別の最小構成へ整理しました。

- `DatabasePostItem`のfixtureとMemory DB seed
- `@sonolus.route.server.post.info`
- `@sonolus.route.server.post.list`
- `@sonolus.route.server.post.detail`
- DB用Postから表示用`PostItem`への変換
- info、list、detail、404のHTTPテスト
- ExampleからのOpenAPI生成script

詳しくは[Post Exampleを動かす](/guide/example)を参照してください。

## 独自DBルート

DB lifecycleと`context.database`を利用しながら、組み込みDBルートを独自デコレーターで置き換えられるようになりました。

```ts
const sonolus = new Honolus({
    database,
    databaseRoutes: false,
})
```

`databaseRoutes`の既定値は`true`なので、既存アプリケーションの動作は変わりません。

## アップグレード

```bash
npm install @untitledsekai/honolus@1.0.1
```

破壊的変更はありません。CLIでOpenAPIを生成するプロジェクトは、更新後に既存コマンドをそのまま再実行できます。
